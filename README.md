# CodeAlpha Web Scraping Project

## 📌 Description
This project extracts quotes from a website using Python.

## 🛠️ Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas

## 📊 Output
The extracted data is stored in a CSV file named `quotes.csv`.

## ▶️ How to Run
1. Install libraries:
   pip install requests beautifulsoup4 pandas
2. Run the script:
   python scraping.py
